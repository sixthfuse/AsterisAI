# Root cause to fix mapping

- **Subject wording was reduced to noisy phrases and passed as a credential/category.** Normalize subject language, clean application framing, preserve family terms, and give exact program names precedence. Evidence: engineering/nursing/technology/biotech program-ID assertions.
- **Applicant credentials could suppress or replace the named target program.** Allow explicit target phrases to override applicant background without converting background credentials into targets. Evidence: 8350BTECH state and Phase 3B applicant-credential gate.
- **Published Red Seal facts were not discoverable across admission conditions.** Search governed admission evidence and return only programs with published Red Seal support. Evidence: 1320ADCERT, 8800BTECH condition 10, 6185ADCERT, 605DDIPMA.
- **International family prose could outrank or lose the certified four-state packet.** Render family international answers directly from certified statuses. Evidence: engineering and nursing comparison packets.
- **Technology Management was treated as a credential and its opaque admission condition was never applied.** Exact-name resolution plus deterministic extraction/evaluation of comparable admission facts. Evidence: rule set 1186, condition 1330, work experience UNMET.
- **Server and browser lacked protocol-output boundaries.** Generic server sanitizer plus browser defense in depth. Evidence: API sanitizer test and browser-state test.
- **Browser default model differed from certification.** Tenant configuration defaults to Sol Medium on every model round. Evidence: active profile gpt-5.6-sol/medium.
- **Platform and institution identities were conflated.** Configurable platform/institution names and deterministic institution voice enforcement. Evidence: BCIT offers/requires; Asteris advises.
